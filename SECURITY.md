# Security Policy

ParaDecomp is designed for high-concurrency enterprise and research agent deployments. We take security vulnerabilities seriously.

---

## 1. Supported Versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |
| < 0.1.0 | No |

---

## 2. Reporting a Vulnerability

If you discover a security vulnerability or exploit vector within ParaDecomp:

1. Do NOT open a public GitHub issue.
2. Email full reproduction steps, payload samples, and affected runtime environment details to: `security@paradecomp.dev`.
3. You will receive an acknowledgment within 24 hours and a coordinated disclosure timeline within 72 hours.
